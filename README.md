# Currículo & Portfólio - Evando José Gaspar

Página estática moderna e futurista para apresentação profissional de Evando José Gaspar, com foco em Dados, Business Intelligence, Python, Power BI, Machine Learning e IA.

## Tecnologias utilizadas

- HTML5
- CSS3 (layout responsivo, estilo futurista / glassmorphism)
- JavaScript (animações simples e utilidades)

## Estrutura do projeto

- `index.html` – Página principal do currículo/portfólio.
- `assets/css/style.css` – Estilos globais da página.
- `assets/js/main.js` – Scripts simples para animações e utilidades.

## Como visualizar localmente

1. Faça o clone ou download deste repositório.
2. Abra a pasta no VS Code ou no explorador de arquivos.
3. Clique duas vezes em `index.html` ou abra o arquivo em um navegador (Chrome, Edge, Firefox).

## Publicando no GitHub Pages

Você vai usar o repositório:

`https://github.com/evandogaspar/evandogaspar.github.io`

Esse é o formato de repositório de **site pessoal** do GitHub. Quando você coloca os arquivos HTML/CSS/JS nele, o GitHub serve automaticamente como um site em:

`https://evandogaspar.github.io`

### Passo a passo

1. No GitHub, crie (ou confirme) o repositório público com o nome **evandogaspar.github.io**.
2. No seu computador, dentro desta pasta do currículo, inicialize o repositório (ou aponte o `remote`) para `evandogaspar/evandogaspar.github.io`.
3. Faça commit de todos os arquivos (`index.html`, pasta `assets`, `README.md`, etc.).
4. Dê push para a branch principal (geralmente `main` ou `master`).
5. Em alguns minutos, o site ficará disponível em:

   `https://evandogaspar.github.io`

Se quiser conferir ou ajustar algo, você pode acessar no GitHub: **Settings > Pages** e confirmar que a fonte está como "Deploy from a branch" usando a branch principal e a pasta raiz (`/`).

Depois disso, use esse link no LinkedIn, processos seletivos e apresentações profissionais.
